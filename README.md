gchboyboy.github.io
====================

This folder is a minimal GitHub Pages site that lists links to your deployed apps. Copy or push these files to a repository named `gchboyboy.github.io` on GitHub to publish at https://gchboyboy.github.io/

Add or edit links in `index.html` under the `<main class="grid">` section.

Quick local preview

```bash
# serve locally from this folder
cd gchboyboy.github.io
python3 -m http.server 8000
# then open http://localhost:8000
```

Publish to GitHub

1. Create a new repository named `gchboyboy.github.io`.
2. Commit and push these files to the `main` (or `master`) branch.
3. GitHub will automatically publish the site at https://gchboyboy.github.io/
